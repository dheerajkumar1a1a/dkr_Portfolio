## Situation

As part of establishing a professional online presence, I needed a reliable, automated deployment workflow for a Next.js-based portfolio site that supports MDX content authoring. The goal was to eliminate manual deployment steps and ensure content changes—such as new project entries or blog posts—go live automatically upon merging to the main branch.

## Task

Design and implement a complete CI/CD pipeline that:
- Lints, type-checks, and builds the Next.js application on every push
- Runs unit and integration tests to prevent regressions
- Deploys preview environments for pull requests
- Promotes to production on merge to `main`
- Supports MDX content collections with frontmatter validation

## Action

1. **Configured GitHub Actions workflows** with separate jobs for linting (`eslint`, `prettier`), type-checking (`tsc --noEmit`), testing (`vitest`), and building (`next build`).
2. **Set up Vercel integration** for automatic preview deployments on every PR and production deployment on merge, including environment variable management for API keys and analytics.
3. **Implemented MDX content pipeline** using `next-mdx-remote` with Zod schema validation for frontmatter, ensuring all portfolio entries conform to required fields (title, date, techStack, summary).
4. **Added automated dependency updates** via Dependabot with auto-merge for patch/minor versions passing CI.
5. **Validated end-to-end** by creating a test portfolio entry (this page) and confirming the full pipeline: local dev → push → PR preview → merge → production deployment.

## Result

- **Zero-downtime deployments** achieved; production updates go live in under 3 minutes after merge.
- **Developer experience improved**: new portfolio entries only require adding an `.mdx` file—no manual build or deploy steps.
- **Pipeline reliability**: 100% success rate across 15+ test deployments from Pune, with automated rollback on build failure.
- **Extensible foundation**: the pipeline now supports future additions like blog RSS generation, sitemap automation, and performance budgets.
